# Cybersecurity-Labs

This repository contains notes and practical evidence from cybersecurity training environments, such as TryHackMe and other hands-on labs. The goal is to show what I have learned and how I applied those concepts in practice, not to reproduce training material.

## Structure

TryHackMe/ contains notes and write-ups from TryHackMe rooms I complete. other-practical-labs/ contains notes and evidence from other hands-on cybersecurity exercises.

## Important notes

This repository does not include flags, room answers, walkthrough solutions, credentials, or any content that violates platform rules. Content reflects my own understanding and application of concepts, not copies of training material. Entries are added only once a lab has genuinely been completed.
